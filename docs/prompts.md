# QuestSmith Prompt Strategy

## Overview

QuestSmith uses Gemini as a narrative engine while the application maintains authority over game state.

### Guiding Principle

Gemini generates:

* Story narration
* NPC dialogue
* Quest ideas
* Item flavor text
* Choice options

The application controls:

* HP
* XP
* Gold
* Inventory
* Level
* Combat outcomes
* Quest status
* Location state
* Persistence

Gemini is never the source of truth for game state.

---

# Prompt 1: Campaign Generation

## Purpose

Create a new campaign for a player after character creation.

## Input

```json
{
  "characterName": "Aria",
  "characterClass": "rogue"
}
```

## Instructions

Generate a cozy fantasy adventure with:

* A memorable campaign title
* A starting location
* A main quest hook
* 3-5 NPCs
* 5-10 locations
* YA fantasy tone
* Light humor
* D&D-inspired adventure

## Required Response

```json
{
  "title": "",
  "mainQuestHook": "",
  "startingLocation": "",
  "npcs": [],
  "locations": [],
  "currentObjective": ""
}
```

# Prompt 2: Scene Generation

## Purpose

Generate the next story scene after a player makes a choice.

## Input

```json
{
  "campaignTitle": "",
  "currentLocation": "",
  "currentObjective": "",
  "character": {},
  "selectedChoice": "",
  "recentHistory": []
}
```

## Instructions

Generate:

* Narrative text
* NPC dialogue if appropriate
* 2-4 player choices

Keep the tone:

* Cozy fantasy
* Funny D&D chaos
* YA adventure

Do not modify game state.

Do not determine combat outcomes.

Do not determine dice roll results.

## Required Response

```json
{
  "narrative": "",
  "choices": [
    {
      "label": "",
      "intent": ""
    }
  ]
}
```

---

# Prompt 3: Combat Narration

## Purpose

Narrate combat results generated by the deterministic game engine.

## Input

```json
{
  "enemy": "Goblin",
  "roll": 17,
  "attackModifier": 2,
  "damage": 4,
  "outcome": "hit"
}
```

## Instructions

Narrate the combat result.

Do not alter numerical values.

Do not invent damage.

Do not invent additional combat outcomes.

## Required Response

```json
{
  "narrative": ""
}
```

---

# Prompt 4: Item Description

## Purpose

Generate flavor text for an item.

## Input

```json
{
  "name": "Lantern of Tiny Courage",
  "type": "quest"
}
```

## Instructions

Generate a fun fantasy description.

Keep the description short.

Do not generate mechanics.

## Required Response

```json
{
  "description": ""
}
```

---

# Prompt 5: Quest Idea Generation

## Purpose

Generate optional side quests.

## Input

```json
{
  "location": "Moonberry Village",
  "campaignTheme": "lost stars"
}
```

## Instructions

Generate a quest idea that fits the existing campaign.

Do not automatically activate the quest.

## Required Response

```json
{
  "title": "",
  "objective": "",
  "summary": ""
}
```

---

# Validation Rules

All Gemini responses must:

* Be valid JSON
* Match the expected schema
* Contain all required fields
* Be validated before rendering
* Be validated before saving

Invalid responses must be rejected.

---

# Architecture Reminder

Gemini provides imagination.

The game engine provides rules.

Firestore provides persistence.

The application remains the authoritative source of game state.
